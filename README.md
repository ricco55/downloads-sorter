# Downloads Sorter

A small Python script that tidies your Downloads folder by moving files into folders by type (Images, Documents, Installers, Archives, Videos, Audio, Code, Other).

It never deletes or overwrites anything.

## What you need
- Windows
- Python

## How to use
Run: `python sort_downloads.py`

## Run it automatically
A weekly Task Scheduler task runs it every Sunday. You can also run it anytime by double-clicking `Tidy Downloads.bat` on your desktop.
